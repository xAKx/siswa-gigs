# SiswaGigs

**A student gig marketplace for UiTM**

[Open the SiswaGigs storyboard](https://xakx.github.io/siswa-gigs/)

**Team members:** Raziq, Dany, Akmal, Faiz, and Iqmal

## About the project

SiswaGigs is our group project for UiTM students to find and apply for small paid jobs. Students can also post a gig when they need help with work such as designing a poster, preparing slides, or editing a video.

A student can post a gig and apply for other gigs using the same account. For example, a student can post a request for help with a club poster while applying for a video editing job.

## How SiswaGigs works

1. **Post a gig.** The poster describes the work and sets the required skills, estimated hours, hourly rate, and application deadline.
2. **Find and apply for a gig.** A student browses or searches the listings, opens the gig details, and applies with a cover letter.
3. **Review applications.** The poster can accept or reject applicants. The student can check the result on **My applications**.
4. **Log hours and view wages.** An accepted student can record their hours and view the wage breakdown, including gross pay, the 10% platform fee, and net pay.
5. **Moderate the platform.** The admin dashboard shows platform totals and includes controls for managing users and gig listings.

## What to try in the storyboard

- From the homepage, select **Browse gigs**, search for `Infographic`, and open the result.
- Use the demo login to open the student dashboard. From there, check **My applications**, **My jobs**, **Work log**, and **Wages**.
- Open the [admin dashboard](https://xakx.github.io/siswa-gigs/admin/dashboard.html) to see the user and gig moderation screens.

This version is an HTML storyboard built with HTML, CSS, and JavaScript. We use hardcoded sample data to demonstrate how the screens and workflows fit together. Login, applications, and payments are simulated. The storyboard has no database, and demo changes do not persist after a reload.
